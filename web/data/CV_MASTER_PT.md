## Tell-AI

CLI agêntico em TypeScript que une LLMs ao terminal para automação de tarefas de desenvolvedor

### Details

É um CLI agêntico que permite automação orientada por LLM, com cadeias de raciocínio multi-etapa, contexto de sessão persistente e execução nativa de comandos
Construído para simplificar workflows complexos de desenvolvedor, conectando LLMs a ambientes de shell locais, com guardrails de segurança configuráveis para execução determinística e segura de comandos
Também ajuda com documentação, pipeline de CI/CD, gerenciamento de VPS, commits e automação de tarefas

### Principais funcionalidades

- Integração com múltiplos provedores de LLM.
- Orquestração de agentes de IA.
- Geração automática de documentação.
- Automação de commits Git.
- Geração automática de Pull Requests.
- Auxílio em pipelines de CI/CD.
- Gerenciamento de servidores VPS.
- Execução segura de comandos com permissões configuráveis.
- Contexto persistente entre sessões.

**Tecnologias**

TypeScript • Node.js • Vercel AI SDK • OpenAI • Claude • Gemini
